# Calculator

A simple calculator built with Java.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Handles invalid input (e.g. division by zero)

## Technologies
- Java

## How to Run
1. Clone the repository
```bash
git clone https://github.com/Y0rii/Calculator.git
```
2. Compile the code
```bash
javac Calculator.java
```
3. Run it
```bash
java Calculator
```
